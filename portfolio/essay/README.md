# Essays

Four short pieces on how results in this repository went wrong, and how each was caught. They are written for anyone who runs experiments, not only for interpretability readers.

| Essay | The lesson |
|---|---|
| [The metric that called a circuit dense](the-metric-that-called-a-circuit-dense.md) | Test a metric on inputs whose answer you know, before the run |
| [A test that encodes the bug](a-test-that-encodes-the-bug.md) | Write tests from the specification, not from the implementation |
| [What a seed pins](what-a-seed-pins.md) | A seed is a claim about a specific object; pin the initialization and test it |
| [The sparse circuit was there all along](grokking-dense-attractor.md) | The original account of the grokking reversal, kept with its corrections |

Each links to the dated entry of the [Honesty Ledger](../RESULTS.md) that records the full account, including what the problem did *not* change.
