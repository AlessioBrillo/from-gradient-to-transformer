# Micro-Phase 34 — The Third Question: the continuum law, third execution

Written as a personal learning log and a public record, like every roadmap
before it.

MP-33 executes the continuum law for the second time: ADR-0007's eight rows
fill — the first research question consumed as artifact, the paper v3 rule
decided, the second question chosen from C5–C8 with the unchosen closed in
the same sitting, the essay annex v3, the shelf at zero, the stranger round 3,

NEW ledger (ADR-0008) and a NEW frozen candidate set (C9–C12, pre-registered
in this file so Session 0 can adjudicate, never improvise).

What is different about the third time: the record has two dated directions,
a live shelf, a paper at v2 or v3, a teaching artifact a stranger has run, and
a verdict history that now includes whichever of C5–C8 opened. The science
has matured from *will grokking reproduce?* to *which of the remaining open
questions is the deepest* — and the answer depends on verdicts that land
between this pre-registration and MP-33's release. This roadmap is therefore
written verdict-agnostic by law: nothing in it re-plans a single row of
MP-29–MP-33; its candidate set is conditioned on their dates.

The deepest law still applies: a promise can be re-planned forever, but a
dated row is answered. This roadmap is pre-registered while MP-29 executes and
MP-30/31/32/33 stand pre-registered, gated in series — so Session 0 is the
mechanical refusal of the stack: no MP-33 release report (ADR-0007 at zero
UNDECIDED rows, the site live, `verify-claims` at 0, the teaching transcript
on disk), no phase. The gate is a checklist with receipts, not a paragraph.

## Design decisions

- **The continuum law, third execution.** Exactly one new research row
  (row 3) opens per phase, chosen at Session 0 from the pre-registered
  candidate set C9–C12 below; the unchosen candidates close with one dated
  reason each, in the same sitting. The session gate is unchanged: a session
  is not over while a row it is responsible for is undated; Session 8
  requires zero UNDECIDED rows. Verdict criteria are written into the row's
  cells **before** the window opens and are never edited afterwards; the
  only allowed post-launch edit is "observed".
- **A new ledger for a new law-execution.** ADR-0007 is full and closed at
  MP-33's release; closed-then-reopened is a NEW row, never a revision
  (inherited). ADR-0008 is this phase's ledger, its eight rows pre-stamped
  with windows and kill-dates at Session 0, its candidate set frozen in this
  file.

  pre-registered; Session 0 only adjudicates. C9–C12 are written below with
  their opens-only-if conditions on MP-29–MP-33 verdicts, so a sitting can
  decide, never improvise.
- **Consumption is execution, not memory (unchanged).** MP-33's row-3 verdict
  (the second research question's result or scheduled negative) is consumed
  into an artifact in the same sitting that owns it (row 1); the paper v4
  opens only if that artifact lands new numbers, else row 2 closes with the
  reason "the v3 is the record" — a dated sentence, never a silence.
- **The record teaches, and the receipt compounds (new this phase).** Row 7

  10-minute talk v2 — because the first artifact's stranger-run transcript

- **The shelf is a row, not a mood (unchanged).** Row 5 carries a heartbeat,

- **The stranger's pipeline extends to round 4.** Row 6 carries the ADR-0004

## Deep-dive study plan

1. **Shortcut learning vs canonical algorithms** (Liu et al., *Transformers
   Learn Shortcuts to Automata*, 2023; Chughtai et al., *A Toy Model of
   Universality*, 2023): what makes a dense solution a legitimate algorithm —
   the C10 reading, deepened by MP-29's characterization and MP-33's verdicts;
   read before S5's protocol is written.
2. **The grokking fragility axis, completed** (Gromov, *Grokking: A Memory
   Perspective*, 2023; Morwani et al., 2024, the edge-of-numerical-stability
   regime; Nanda et al., 2023; Power et al., 2022): weight decay as the
   canonical circuit-forming pressure, and what the wd-frontier verdict (C5's)
   means for the harness — the reading that turns C5's closure into C10's
   evidence.
3. **The dense solution's structure** (the DFT's full-support expansion; the
   frequency-ablation evidence already on disk): norm structure per layer,
   per-head Fourier dictionaries, the embedding-renormalization interaction —
   studied as theory before the theory note's claims are written.
4. **SAEs where the circuit is dense** (Bricken et al., 2023; Cunningham et
   al., 2024): L0/FVE/dead-features on the dense residual stream — the C7
   prediction ("the SAE struggles exactly where the circuit is dense") read
   as evidence once the data exists.
5. **Induction heads at scale** (Olsson et al., 2022; the d_model ≈ 128
   formation floor; weight decay in attention-only models): the C11/C12 fork —
   either reading is a dated verdict by MP-33's release.
6. **The circuit portrait method** (Olah et al., *Zoom In: An Introduction to
   Circuits*, 2020; Elhage et al., *A Mathematical Framework for Transformer
   Circuits*, 2021; Wang et al., *Interpretability in the Wild*, 2023):
   QK/OV decomposition, logit lens, head-role maps — the C12 craft, worth
   learning regardless of which fork R1 lands on.
7. **The record teaches, round two**: turning the second verdict set into a
   second runnable artifact — the walkthrough-v2 craft and the 10-minute-talk
   v2; the four-register distillation (paper / annex / 30-second spoken claim
   / 5-minute teaching explanation) with the delta between registers as the
   leak detector.

## Strategic tips and architectural best practices

- **The one-question law, third execution.** A phase that opens two research
  questions is drift by another name; the unchosen candidates close in the
  same sitting as the choice. The continuum law is the mechanical refusal of
  this drift — proven executable twice, it must simply be executed again.
- **The candidate set is frozen before S0, never improvised at it.** C9–C12
  are pre-registered in this file, conditioned on MP-29–MP-33 verdicts; a
  sitting decides, it never invents. The unchosen close with dated reasons
  in the same sitting as the choice.
- **Consumption is execution.** A verdict consumed into an artifact in the
  same sitting is a result; consumed into a paragraph written later it is a
  memory. Row 1 consumes ADR-0007's row-3 verdict in the sitting that owns it.
- **The record teaches, and the receipt compounds.** The second runnable
  artifact is only worth shipping because the first one's transcript proved
  the format; the showcase's story is now "read it, run it, watch me be wrong
  on the record."
- **Verdict-agnostic by law.** This roadmap re-plans nothing of MP-29–MP-33;
  its candidates are conditions, not predictions. The fork drill (Ex-H) keeps
  both futures written without pre-committing to either.
- **The shelf is a row, not a mood.** Year two begins with a heartbeat and a
  hostile-webmaster transcript; a live public number that exceeds the record
  is a blocked row, not a to-do.
- **Annexes are amended, never rewritten.** Annex v4 inherits the annex
  doctrine: a new annex appears via a dated fork, the original preserved.
- **The S0 gate is a checklist with receipts.** MP-33's release report
  (ADR-0007 at zero, the live URL, `verify-claims` at 0, the teaching
  transcript on disk) is a condition with artifacts, not a paragraph — five
  phases stacked without execution would be the permanent warning made real,
  and Session 0 refuses it mechanically.
- **The negative stays the signature.** The row that closes with one reason
  is stamped like the row that launched; the third question earns its verdict
  or its scheduled negative with equal polish.
- **The debt row re-verifies; it never re-does.** A stamped closure is
  re-checked with its transcript; a genuinely new debt cell is a NEW row,
  never a revision. A pending item cannot outlive a ledger — the exp5
  1000-epoch promise lands in S1 as a dated row or closes with its reason.
- **Architecture laws unchanged.** `dev` only, GPG-signed, Conventional
  Commits with `(meta)`, `(portfolio)`, `(ci)` scopes; CI green before any
  merge; the floor re-verified locally before every push; zero UNDECIDED rows
  at Session 8; release = merge + 14 calendar days.
- **The showcase 30-second story**: *the program's third pre-registered
  question ran to a dated verdict, the record taught it twice in runnable
  artifacts, and every public number still re-derives from one command
  line.* Every artifact this phase launches is written to that standard.
