before it.

second question's verdict produces new numbers, and the record finally
teaches — one public artifact a stranger can actually run, not just read.

The deepest law still applies: a promise can be re-planned forever, but a
dated row is answered. This roadmap is pre-registered while MP-29 executes and
MP-30/31/32 stand unexecuted — four phases stacked is the exact drift the
record has named since MP-18 — so Session 0 is the mechanical refusal of it:
no MP-32 release report (ADR-0006 at zero UNDECIDED rows, the site live,
`verify-claims` at 0), no phase. The gate is a checklist with receipts, not a
paragraph.

## Design decisions

- **The continuum law, second execution.** Exactly one new research row
  (row 3) opens per phase, chosen at Session 0 from the pre-registered
  candidate set C5–C8 below; the unchosen candidates close with one dated
  reason each, in the same sitting. The session gate is unchanged: a session
  is not over while a row it is responsible for is undated; Session 8
  requires zero UNDECIDED rows. Verdict criteria are written into the row's
  cells **before** the window opens and are never edited afterwards; the only
  allowed post-launch edit is "observed".
- **A new ledger for a new law-execution.** ADR-0006 is full and closed at
  MP-32's release; closed-then-reopened is a NEW row, never a revision
  (inherited). ADR-0007 is this phase's ledger, its eight rows pre-stamped
  with windows and kill-dates at Session 0, its candidate set frozen in this
  file.
- **The candidate set is frozen here, not at S0.** The law says the set is
  pre-registered; Session 0 only adjudicates. C5–C8 are written below with
  their opens-only-if conditions, so a sitting can decide, never improvise.
- **Consumption is execution, not memory (unchanged).** MP-32's row-3 verdict
  (the first research question's result or scheduled negative) is consumed
  into an artifact in the same sitting that owns it (row 1); the paper v3
  opens only if that artifact lands new numbers, else row 2 closes with the
  reason "the v2 is the record" — a dated sentence, never a silence.
- **The record teaches (new this phase).** The teaching lane (row 7) is a
  first-class row, not an afterthought: one public artifact a stranger can
  run — the Colab grokking notebook (the negative + the dense reading,
  executable), the walkthrough v2, or the 10-minute talk v2 — shipped with a
  date, exactly like a verdict. The showcase's 30-second story now has a
  "run it yourself" clause.
- **The shelf is a row, not a mood (unchanged).** Row 5 carries a heartbeat,
  a hostile-webmaster walk at zero, and a dated close-or-launch — baseline in
  S1, rehearsal in S7, release in S8. A live public number that exceeds the
  record is a blocked row, not a to-do.
- **The stranger's pipeline extends to round 3.** Row 6 carries the ADR-0004
  human-dependency rule: intake at S4, kill-date at S5, the self-review
  substitute written in S2 from the visitor's chair. Never a silent skip.
- **The debt row re-verifies, it never re-does.** Row 8 re-verifies MP-32's
  stamped closures (W&B, clean-clone proof, graduation proof,
  `reproduce-multiseed` exp2/exp5) with dates and transcripts — a claimed
  closure without its transcript stays open, and a NEW debt cell lands as a
  NEW row, never a revision.
- **The S0 gate is the mechanical refusal of drift (unchanged, now four
  phases deep).** Session 0 opens only on MP-32's release report: ADR-0006 at
  zero UNDECIDED rows, the site live, `verify-claims` at 0, `dev == main`.
  The MP-26 precedent is named and refused again: the gate is a checklist
  with receipts.
- **The terminus is stamped at Step 0**: release = this roadmap's merge + 14
  calendar days. On that date the phase ships everything the rows decided —
  the residue is a dated list, never a silence.

## Deep-dive study plan

1. **The weight-decay axis of grokking fragility** (Gromov, *Grokking: A
   Memory Perspective*, 2023; Morwani et al., 2024, the edge-of-numerical-
   stability regime; Nanda et al., 2023; Power et al., 2022): what a wd sweep
   must measure, why decay is the canonical circuit-forming pressure, and the
   reading that makes the C5 choice a decision, not a mood — read before S5's
   protocol is written.
2. **The dense-solution theory** (the DFT's full-support expansion; Liu et
   al., *Transformers Learn Shortcuts to Automata*, 2023; Chughtai et al.,
   *A Toy Model of Universality*, 2023): is the dense solution a shortcut or
   a legitimate alternative algorithm — the study MP-29's characterization
   opened, deepened by the second question's verdict.
3. **Induction heads at scale** (Olsson et al., 2022; the d_model ≈ 128
   formation floor; weight decay in attention-only models): the C6 reading,
   if the R1 no-head negative makes it a live choice.
4. **SAEs on dense streams** (Bricken et al., 2023; Cunningham et al., 2023):
   L0/FVE tradeoffs and what density does to dictionary learning — the C7
   prediction ("the SAE struggles exactly where the circuit is dense") read
   as theory before the data exists.
5. **ACDC and the EAP lineage** (Conmy et al., 2023; Hanna et al., 2024):
   the C8 reading, gated on the pilot's verdict.
6. **Heterogeneous-feature superposition** (Elhage et al., 2022, ch. 2–3) —
   if MP-32 ran C3, this is the consumed-verdict reading that makes row 1 a
   verdict read correctly, not a re-run.
7. **The record teaches**: turning a negative-result research record into
   teaching artifacts — the Colab notebook craft, the three-register
   distillation (paper sentence / annex sentence / 30-second spoken claim,
   plus the 5-minute teaching explanation), and how a stranger-run receipt
   makes a showcase claim auditable.

## Strategic tips and architectural best practices

- **The one-question law, second execution.** A phase that opens two research
  questions is drift by another name; the unchosen candidates close in the
  same sitting as the choice. The continuum law is the mechanical refusal of
  this drift — now proven executable once, it must simply be executed again.
- **The candidate set is frozen before S0, never improvised at it.** C5–C8
  are pre-registered in this file; a sitting decides, it never invents. The
  unchosen close with dated reasons in the same sitting as the choice.
- **Consumption is execution.** A verdict consumed into an artifact in the
  same sitting is a result; consumed into a paragraph written later it is a
  memory. Row 1 consumes ADR-0006's row-3 verdict in the sitting that owns it.
- **The record teaches.** The showcase's deepest upgrade is not more prose —
  it is one artifact a stranger can run, with the run-transcript as its
  receipt. The teaching lane ships with a date, exactly like a verdict.
- **The shelf is a row, not a mood.** Maintenance has dates, heartbeats and a
  hostile-webmaster transcript; a live public number that exceeds the record
  is a blocked row, not a to-do.
- **Annexes are amended, never rewritten.** Annex v3 inherits the annex
  doctrine: a new annex appears via a dated fork, the original preserved.
- **The S0 gate is a checklist with receipts.** MP-32's release report
  (ADR-0006 at zero, the live URL, `verify-claims` at 0) is a condition with
  artifacts, not a paragraph — four phases stacked without execution would be
  the permanent warning made real, and Session 0 refuses it mechanically.
- **The negative stays the signature.** The row that closes with one reason
  is stamped like the row that launched; the continuum's second question
  earns its verdict or its scheduled negative with equal polish.
- **The debt row re-verifies; it never re-does.** A stamped closure is
  re-checked with its transcript; a genuinely new debt cell is a NEW row,
  never a revision.
- **Architecture laws unchanged.** `dev` only, GPG-signed, Conventional
  Commits with `(meta)`, `(portfolio)`, `(ci)` scopes; CI green before any
  merge; the floor re-verified locally before every push; zero UNDECIDED rows
  at Session 8; release = merge + 14 calendar days.
- **The showcase 30-second story**: *the program's second pre-registered
  question ran to a dated verdict, the record taught it to strangers in one
  runnable artifact, and every public number still re-derives from one
  command line.* Every artifact this phase launches is written to that
  standard.
